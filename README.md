## Overview

A software-as-a-service platform for business users, providing a subscription-style web application with accounts and a shared online workspace.

## General scenario

- User accounts and role-based access at a general level
- A web dashboard for everyday business tasks, described only in general terms
- Subscription-oriented structure for different user groups
- A responsive experience on mobile and desktop
